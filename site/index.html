Use your terminal

The commands include the CLI and skills for all three agents.

macOS With Homebrew
Need Homebrew?
brew install python yt-dlp
export PATH="$HOME/.local/bin:$PATH"
curl -fsSL https://raw.githubusercontent.com/gvkhosla/ytmd/v0.5.0/install.sh -o /tmp/install-ytmd.sh
sh /tmp/install-ytmd.sh --agent all
ytmd doctor
Linux With Python + pipx

First install Python 3.9+ with SQLite FTS5 and pipx using your package manager.

Then run
pipx install yt-dlp
export PATH="$HOME/.local/bin:$PATH"
curl -fsSL https://raw.githubusercontent.com/gvkhosla/ytmd/v0.5.0/install.sh -o /tmp/install-ytmd.sh
sh /tmp/install-ytmd.sh --agent all
ytmd doctor

The installer checks dependencies and release checksums. Add ~/.local/bin to your shell profile’s PATH if it isn’t there already. Install options ↗

Or run the commands directly

These examples use a real video: Fireship’s JavaScript in 100 Seconds.

Save the source

Fetch available captions once and keep them locally.

ytmd add "https://youtu.be/DHjqpvDnNGE" --json

See the outline

Metadata and chapters, without the full transcript.

ytmd info DHjqpvDnNGE

Gather task evidence

Get source passages, citations, and explicit omissions—not a generated summary.

ytmd context DHjqpvDnNGE --query "javascript" --max-chars 4000 --json

Read deeper

Follow bounded pages, or select a chapter. Continue with the returned cursor.

ytmd read DHjqpvDnNGE --max-chars 4000 --json

Read llms.txt ↗
Storage
SQLite is the source of truth. Markdown is a generated export. Set YTMD_DIR to change the location.
Captions, not transcription
Videos need available captions. Captions can contain mistakes; ytmd doesn’t transcribe audio.
Your agent does the reasoning
The CLI retrieves evidence. The skill guides your existing agent to explain it, preserve qualifications, and label adaptations. See what is tested.
Network access
Fetching captions contacts YouTube. Saved content works offline. Browser cookies are only read if you explicitly request it.
