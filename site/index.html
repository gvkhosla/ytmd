01A URL is all you need
yt-dlp fetches the available captions. ytmd keeps the text and timestamps, without downloading the video.
02Files you can keep
Raw captions and search live in SQLite. Readable markdown sits alongside it. No proprietary workspace to maintain.
03Context, not a context dump
Find matching passages, read a time window, and cite the source. Works from Pi, Codex, Claude Code, or your terminal.

Get started / v0.2.0

Your next video.
Your next coding session.

Install the CLI and agent skill. Restart your agent. Then give it a YouTube URL.

Requires Python 3.9+ with SQLite FTS5 and yt-dlp. The installer checks dependencies and release checksums.

Rather let your agent set it up?

Install ytmd from https://github.com/gvkhosla/ytmd. Read the README and installer first, check my dependencies, and ask before making system changes. Install the CLI and skill for my agent, then verify with ytmd doctor.

With Homebrew installed, paste into your terminal:

brew install python yt-dlp
curl -fsSL https://raw.githubusercontent.com/gvkhosla/ytmd/v0.2.0/install.sh -o /tmp/install-ytmd.sh
sh /tmp/install-ytmd.sh --agent all
export PATH="$HOME/.local/bin:$PATH"
ytmd doctor

Then restart your agent and ask

Save this YouTube video and apply the relevant ideas to this repository: [paste URL]

Installs skills for Pi, Codex, and Claude Code. No sudo or shell-profile edits by the installer. Install options ↗

Also works without an agent

Three commands.
That’s the workflow.

No special integration required. Your agent can call the same commands you do.

Save

ytmd "YOUTUBE_URL"

Search

ytmd search "cache invalidation"

Read a window

ytmd show VIDEO_ID --from 12:00 --to 15:00

Add --json for machine-readable output.

Small by design. Honest about the limits.

ytmd uses available captions, not audio transcription. Videos without captions aren’t supported, and captions can contain mistakes. Search matches words, not meaning. YouTube restrictions and rate limits still apply.

Your library stays local. Fetching captions contacts YouTube. No browser cookies are read unless you explicitly request it.
